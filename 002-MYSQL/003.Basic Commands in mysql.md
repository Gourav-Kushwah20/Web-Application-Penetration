## Connecting to MySQL Server

Connect to the MySQL server at host **192.168.1.31** as user **root**.The -p flag prompts for a password.
```bash
mysql -u root -h 192.168.1.31 -p
```

Connect to the MySQL server at host **192.168.1.30** as user **armour**.The -p flag prompts for a password.
```bash
mysql -u armour -h 192.168.1.30 -p
```
Connect server using the user **armour** with the password **123**.
```bash
mysql -u armour -h 192.168.1.30 -p123
```

# ✅ Steps to Create a MySQL User in phpMyAdmin
### 1. Log in to phpMyAdmin

    Open your browser and go to: http://localhost/phpmyadminhttp://yourserveripaddress/phpmyadmin or your server’s phpMyAdmin URL.

    Log in using a MySQL account with admin privileges (e.g., root).

### 2. Go to “User Accounts”
In the top menu, click on the "User accounts" tab.
### 3. Click “Add user account”
Scroll down if needed and click the “Add user account” button.
![alt text](<img/Create User.png>)

### 4. Fill in User Details

| Field           | Value                                                                  |
|----------------|------------------------------------------------------------------------|
| **Username**    | Choose a username (e.g., `devuser`)                                     |
| **Host name**   | Select `%` (any host), or `localhost`, or specify an IP (e.g., `192.168.1.100`) |
| **Password**    | Set a strong password (e.g., `StrongP@ss123`)                           |
| **Re-type password** | Confirm the password to avoid typos                                 |


    ✅ Optionally check:

    ✅ "Create database with same name and grant all privileges"

    ✅ "Grant all privileges on wildcard name (username_%)"

![alt text](<img/Create user1.png>)

### 5. Global Privileges (Optional)
    Scroll to Global privileges.

    If you want full access: check Check all.

    If you're limiting access, select only needed permissions.

### 6. Click “Go”
    Scroll to the bottom and click the “Go” button.

    You’ll see a success message like:

    “You have added a new user.”

# ✅ Basic Database Operations Commands

- Display a list of all databases on the MySQL server.

```sql
Show databases;
```
- Create a new database named db_name.
```sql
create database db_name;
```
- Switch to the database db_name to perform operations with it.
```sql
use db_name;
```
- Remove the specified database and all its contents.
```sql
drop database db_name;
```
- Create a sample database named db_name.
```sql
create database armour_db;
```
- Switch to the armour_db database.
```sql
use armour-db;
```
- Display all tables within the selected database.
```sql
show tables;
```
# Creating And Managing Tables
Create a table named **users** with five columns: **id, name, email, password and enable**.
```sql
create table users (
     id INT,
     name VARCHAR(50),
     email VARCHAR(50),
     password VARCHAR(50),
     enable INT(1)
     );
```
Create another table named **users1** with a similar structure.
```sql
create table users1(
     id INT,
     name VARCHAR(50),
     email VARCHAR(50),
     password VARCHAR(50),
     enable INT(1)
     );
``` 
Show all columns and metadata from the **users** table.
```bash
show columns from users;
```
Display the structure of the **users** table using the **DESC** keyword.
```bash
DESC users;
```
Use **DESCRIBE** to show detailed information about **users**.
```bash
DESCRIBE users;
```
Delete the **user1** table from the database.
```bash
DROP TABLE users1;
```
### Summary Of Table Operations
- **SHOW TABLES :** List tables in the current database.
- **Create Table :** Define a new table with schema.
- **SHOW COLUMNS , DESC, DESCRIBE :** Show columns definitions.
- **DROP TABLE :** Delete a table completely.
