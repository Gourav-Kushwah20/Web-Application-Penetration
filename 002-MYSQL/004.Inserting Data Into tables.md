# Inserting Data Into Tables
Insert a single row into a table with specified column values.

```sql
INSERT INTO tablename(column1,column2,column3)
VALUES(val1,val2,val3);
```
Insert a new row into the users table int the **armour_db** database.
```sql
INSERT INTO users(id, name, email, password, enable)
VALUES(1, 'admin', 'admin@armour.com', '@rmour123',1);
```
Insert another user into the same table.
```sql
INSERT INTO users(id, name, email, password, enable)
VALUES(2, 'rahul', 'rahul@armour.com', '@rmour123',1);
```
Add a disabled user record.
```sql
INSERT INTO users(id, name, email, password, enable)
VALUES(3, 'ankit', 'ankit@armour.com', 'pass123',1);
```
check user tables data cmd:
```sql
select * from users;
```

# Common MySQL Constraints

MySQL constraints are rules used to enforce data integrity in a database table.

## 🔒 Constraint Types

| Constraint        | Description |
|------------------|-------------|
| `NOT NULL`        | Ensures that a column cannot have NULL values. |
| `UNIQUE`          | Ensures all values in a column are different. |
| `PRIMARY KEY`     | Uniquely identifies each record and create and index|
| `FOREIGN KEY`     | Ensures referential integrity by linking to a column in another table. |
| `CHECK`           | Ensures values meet a specific condition (supported in MySQL 8.0+). |
| `DEFAULT`         | Provides a default value when no value is specified. |
| `AUTO_INCREMENT`  | Automatically increases numeric values, commonly used for primary keys. |

---
## 👤 Creating tables with Constraints
Create a **user2** table with multiple constraints like **NOT NULL,UNIQUE, CHECK** and **DEFAULT**.

```sql
create table user2(
id INT(11) NOT NULL AUTO_INCREMENT,
name VARCHAR(255) NOT NULL,
age INT NOT NULL CHECK (age >=16),
email VARCHAR(255) NOT NULL UNIQUE,
password VARCHAR(255) NOT NULL,
course_name VARCHAR(255) NOT NULL DEFAULT "IT Security",
enable INT(1) NOT NULL,
PRIMARY KEY(id)
);
```

## Inserting Data Into Tables With Constraints

Insert a valid row into the user2 table.
```sql
INSERT INTO user2(id, name, age, email, password, course_name, enable)
VALUES (1, 'admin', 20, 'admin@armour.com', 'password123','Linux',1);
```
Insert a row while skipping the **id** column (auto-increment).
```sql
INSERT INTO user2(name, age, email, password, course_name, enable)
VALUES ('rahul', 18, 'rahul@armour.com', 'pass123','',1);
```
Insert a row using default value for **course_name.**
```sql
INSERT INTO user2(name, age, email, password,enable)
VALUES ('rahul1', 18, 'rahul1@armour.com', 'pass123',1);
```
Omit the **age** field (invalid if NOT NULL constraint is applied)
```sql
INSERT INTO user2(name, email, password, enable)
VALUES ('rahul1', 'rahul1@armour.com', 'pass123',1);
```
Insert multiple users at once into **user2**.
```sql
INSERT INTO user2(name, age, email, password, enable)
VALUES
('u1' , 18 , 'u1@armour.com', 'pass123',0),
('u2' , 20 , 'u2@armour.com', 'pass123',1),
('u3' , 21 , 'u3@armour.com', 'pass123',0),
('u4' , 20 , 'u4@armour.com', 'pass123',1),
('u5' , 20 , 'u5@armour.com', 'pass123',1);
```

## Notes
- Use constraints to ensure data integrity and validation.
- Prefer AUTO_INCREMENT for primary keys.
- Use DEFAULT values to reduce redundant input.
- Multiple inserts are more efficient than many single inserts.
