# Alter table in MySQL
The **ALTER TABLE** statement in MySQL is used to make changes to the structure of an existing table.

**Create Example Table**
``` sql
CREATE TABLE student1(
    id INT(10) NOT NULL AUTO_INCREMENT,
    name VARCHAR(255) NOT NULL,
    age INT NOT NULL,
    gender VARCHAR(1) NOT NULL,
    email VARCHAR(255) NOT NULL UNIQUE,
    percentage INT(3) NOT NULL,
    PRIMARY KEY(id)
);
```
```sql
DESC student1;
```
**Add Column** 
```sql
ALTER TABLE student1
ADD enable INT(1);
```
**Change Column Order**
```sql
ALTER TABLE student1
MODIFY enable INT(1) NOT NULL AFTER email;
```

**Rename Column**
```sql
ALTER TABLE student1
CHANGE id ID INT(10) NOT NULL;
```
**Rename name to Full_Name**
```sql
ALTER TABLE student1
CHANGE name Full_Name VARCHAR(255) NOT NULL;
```
**Drop Column**
```sql
ALTER TABLE student1
DROP COLUMN enable;
```
**Rename Table**
Rename student1 to student2
```sql
ALTER TABLE student1
RENAME TO student2;
```
