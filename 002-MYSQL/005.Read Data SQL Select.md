# Read data SQL Select
## SQL Select(Read Data)
The **SELECT** statement in SQL is used to read or retrieve data from one or more tables.It is the most commonly used SQL command for data retrievel.

### Basic Syntax 
```sql
SELECT column1, column2, ...
FROM table_name
WHERE condition
ORDER BY column
LIMIT number
```
### Read All Data
```sql
SELECT * From table_name;
```
Fetches **all columns** form the tables.

**Example:**
```sql
SELECT * From user2;
```
```sql
SELECT id,name,age From user2;
```
### Read Specific Columns
```sql
SELECT column1,column2,column3 From Table_name;
```
**Example:**
```sql
SELECT name,email From user2;
```
### Filter Rows (WHERE Clause)
```sql
SELECT * FROM table_name WHERE condition;
```
**Example:**
```sql
SELECT * FROM user2 WHERE age>20;
```
```sql
SELECT * FROM user2 WHERE enable=1;
```
### Logical Operator (AND,OR,NOT)
```sql
SELECT * FROM table_name WHERE condition1 AND contition2;
SELECT * FROM table_name WHERE condition1 OR contition2;
SELECT * FROM table_name WHERE NOT contition;
```
### Pattern Matching(LIKE,REGEXP)
```sql
SELECT * FROM table_name WHERE Column LIKE 'pattern';
```
```sql
SELECT * FROM table_name WHERE Column REGEXP 'regex';
```
### Range and set Filtering
```sql
SELECT * FROM table_name WHERE Column IN (value1, value2);
```
```sql
SELECT * FROM table_name WHERE Column BETWEEN val1 AND val2;
```
### Sorting Data
```sql
SELECT * FROM table_name ORDER BY column ASC|DESC;
```
### Unique Values
```sql
SELECT DISTINCT column FROM table_name;
```
### NULL Checks
```sql
SELECT * FROM table_name WHERE column IS NULL; 
```
```sql
SELECT * FROM table_name WHERE column IS NOT NULL; 
```
### Limit and Pagination
```sql
SELECT * FROM table_name LIMIT 5; 
```
```sql
SELECT * FROM table_name LIMIT offset, count; 
```
### Aggregate Functions
```sql
SELECT COUNT(column) FROM table_name;
```
```sql
SELECT SUM(column) FROM table_name;
```
```sql
SELECT AVG(column) FROM table_name;
```
```sql
SELECT MAX(column) FROM table_name;
```
```sql
SELECT MIN(column) FROM table_name;
```

## Select WHERE Clauses
1. Select users with id in (5, 9):
```sql
SELECT * FROM user2 WHERE id IN (5, 9);
```
- Returns all rows where the id is either 5 or 9.

2. Select users with id in (4, 6, 8):
```sql
SELECT * FROM user2 WHERE id IN (4,6, 8);
```
- Returns all rows where the id is either 4, 6, or 8.

3. Select users with age in (18, 20):
```sql
SELECT * FROM user2 WHERE age IN (18, 20);
```
- Returns all rows where the age is either 18 or 20
