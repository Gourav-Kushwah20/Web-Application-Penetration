
# 🗃️ Database Overview

## 📌 What is a Database?

A **database** is an organized collection of data that is stored and accessed electronically. It allows for efficient data management, retrieval, and manipulation.

---

## 🧩 Types of Databases

### 1. 📊 Relational Databases (RDBMS)
- Store data in **tables** (rows and columns)
- Use **SQL (Structured Query Language)**
- Ensure data **integrity** and **relationships** between tables

🔸 **Examples:** MySQL, PostgreSQL, Oracle, SQL Server

---

### 2. 📁 NoSQL Databases
- Handle **unstructured or semi-structured** data
- Use flexible **schema-less** design
- Support high **scalability**
- Use alternative data model(e.g., document-oriented, key-value, graph databases). 

🔸 **Examples:** MongoDB, Cassandra, Redis, CouchDB

---

### 3. ☁️ Cloud Databases
- Hosted on cloud platforms
- Scalable, highly available, and secure
- Often offer automated backups and replication

🔸 **Examples:** Amazon RDS, Google Cloud Firestore, Azure SQL Database

---
# Why Use a Database?
✅ Why Use a Database?
1. **Efficient Data Storage :**
Saves large amounts of data in a structured way.

2. **Fast Access and Retrieval :**
Quickly find and retrieve specific information using queries.

3. **Data Accuracy and Consistency :**
Ensures data remains correct through rules (like constraints or validations).

4. **Security :**
Restricts who can access or modify the data (authentication and permissions).

5. **Concurrent Access :**
Multiple users or apps can use it at the same time without conflicts.

6. **Backup and Recovery :**
Allows data to be backed up and restored after failures.

7. **Scalability :**
Grows with your application as data and user demand increase.

8. **Data Relationships :** 
Easily links related data (e.g., customers and their orders).

# 🔑 Key Characteristics of a Database

- **Structured Data Storage:** Data is stored in a structured manner(e.g., tables ,rows ,columns in relational databases),which makes it easier to search and reterive.
- **Persistent Storage:** Data in a database is stored on disk and persists even the system reboots.
- **Data integrity** databases ensure data consistency and integrity using constraints and relationships(e.g., primary keys, foreign keys).
- **Data Security:** Access to data can be controlled using authentication, permissions, and encriptions.
- **Efficient Data Access:** Databases support fast queries, indexing and optimized data retrieved.

## 📘 Database Management System (DBMS)
A Database Management System (DBMS) is software that stores, manages, and retrieves data in databases. It acts as a bridge between application and the data itself, ensuring data integrity, security and efficient access.

**Examples of DBMS:**
- **MySql :** Popular open-source DBMS, widely used with PHP-based applications.

- **MariaDB :** MySQL-compatible, also open-source and community-driven.
- **PostgreSQL :** Advanced open-source DBMS supporting complex data types, often used with python and PHP.
- **Microsoft SQL Server :** Enterprise-level DBMS, common in .NET applications.
- **Oracle RDBMS :** Robust DBMS for large-scale applications, often in Java environments.
- **IBM DB2 :** Enterprise DBMS by IBM, Known for performance and scalability.
- **Mongo DB :** NoSQL database for unstructured, document-oriented data.
- **SQLite :** Lightweight embedded DBMS, ideal for mobile and desktop apps.

## 🔐 Key Database Concepts

- **Table**: Basic structure storing data in rows and columns
- **Primary Key**: Uniquely identifies a record
- **Foreign Key**: Links two tables together
- **Index**: Speeds up data retrieval
- **Transaction**: A set of operations that must succeed or fail as a whole
---

## Database Structure
- **Database:** A set of tables; 1 database = 1 applications; access permissions are set at the database level.
- **Tables:** A set of columns and rows, representing a single concept (like users,orders,products).
- **Column:** A single type of data (e.g., first_name, last_name, email).
- **Row:** A single record (e.g., rahul, jain, rahul@armourinfsec.com).
- **Field:** the intersections of a column and a row (e.g., first_name: rahul).
- **Index:** A data structure to speed up lookups,similar to index of a book.
- **Foreign Key:** A column referencing rows in another table-foundation of relational databases.
