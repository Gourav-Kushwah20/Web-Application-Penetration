# 🔐 Resetting MySQL Root Password on Debian

This guide provides **step-by-step instructions** to reset the MySQL **root** password.
These commands are helpful if you've **forgotten the password** or need to **update it for security reasons**.

Follow the steps below 👇

---

## ✅ **Step 1: Stop the MySQL Service**

Before resetting the password, stop the MySQL service to avoid conflicts.

```bash
sudo systemctl stop mysql
```

---

## 🔍 **Step 2: Verify That MySQL is Stopped**

Check whether MySQL processes are still running:

```bash
sudo netstat -nltup | grep mysql
```

If **no output appears**, MySQL has successfully stopped. 👍

---

## 🛠️ **Step 3: Start MySQL Without Grant Tables**

Starting MySQL with `--skip-grant-tables` disables authentication.
This allows you to log in without a password.

```bash
sudo mysqld_safe --skip-grant-tables &
```

This runs MySQL in **safe mode** & disables user authentication temporarily.

---

## 🔑 **Step 4: Log in as Root (No Password Required)**

```bash
mysql -u root
```

Since authentication is disabled, you **won’t be asked for a password**.

---

## 🗄️ **Step 5: Switch to the MySQL Database**

The `mysql` database stores all user account details.

```sql
USE mysql;
```

---

If you want, I can also complete **Step 6 onward** (updating password, restarting service, securing installation).

## ✅ Method: Update MySQL Root Password (If You Know the Current Password)
There are two main methods for resetting the root password.

🔐 **Method 1: Update Statement** 

This works on old versions of MYSQL:
```sql
    update user set password=PASSWORD('NEW-ROOT_PASSWORD') where User='root';
```
Replace **NEW-ROOT_PASSWORD** with your desired secure password.

🛠️**Method 2 : ALTER USER Statement (Recommended for Mysql 5.7+ / 8.0+)** 

- ✅ This is the modern and recommended approach:
```sql
    ALTER USER 'root'@'localhost' IDENTIFIED BY 'new_secure_password';
```
Replace 'new_secure_password' with your desired password.

💾 **Step 6: Exit MYSQL and Restart The Service**

Exit The MySQL shell:
```sql
    exit;
```
 **Step 7: Then, restart the MYSQL service to re-enable authentication:**

🔎 **Check Password Update**

```bash
    sudo systemctl restart mysql
```

**Step 8: Login with the new Password by logging back into MYSQL:**

Finally, test the new password by logging back into Mysql:

```bash
   mysql -u root -p
```
when prompted, enter your new **root** password.

# Allowing Remote Connections to MySQL on Debian

This guide explains how to allow remote MySQL connections on a Debian-based system (Debian, Ubuntu, etc.).

---

## ✅ Prerequisites

- MySQL Server installed
- Root or sudo access
- Your firewall allows port 3306

---

## 1. Update MySQL Configuration File

Open the MySQL configuration file. Edit the `/etc/mysql/mysql.conf.d/mysqld.cnf` file:

```bash
vim /etc/mysql/mysql.conf.d/mysqld.cnf
```
Find this line:

```bash
bind-address = 127.0.0.1
```
Change it to:

```bash
bind-address = 0.0.0.0
```
This allows MySQL to listen on all network interfaces.

- 127.0.0.1 : Only allows local connections.
- 0.0.0.0   : Allows connections from any IP address.

## 2.Restart MySQL Service
To apply the configuration changes,restart the MySQL service:
```bash
systemctl restart mysql
```
## 3.Update MySQL User Permissions
Existing Users in MySql
```sql
use mysql;
```
```sql
mysql> SELECT user,host FROM mysql.user;
```
## 4.Steps to Create Remote Access for Root
- Create The User
```sql
CREATE USER 'ROOT'@'%' IDENTIFIED BY 'root';
```
- Grant All Privileges
```sql
mysql> GRANT ALL PRIVILEGES ON *.* TO 'ROOT'@'%' WITH GRANT OPTION;
```
- Apply Changes
```sql
FLUSH PRIVILEGES;
```
- Confirm User Creation
Re-run:
```sql
SELECT user,host FROM mysql.user;
```
You Should see:
| User       | Host        | Description                                                                 |
|------------|-------------|-----------------------------------------------------------------------------|
| root       | localhost   | Allows local login only (via socket or 127.0.0.1).                          |
| ROOT       | %           | Allows 'ROOT' login from any host, but is a different user than `root`.     |


## 5. Adjust the Firewall Rule(Optional)
Allow incoming connection to MySQL's default port **3306** using your System's firewall.

For Example,with ufw (Uncomplicated Firewall):

```bash
sudo ufw allow 3306/tcp
```
```bash
sudo ufw reload
```

Check status:

```bash
sudo ufw status
```
## 6. Connect from a Remote Machine
From a client (e.g., Windows CMD or another server):

```bash
mysql -u remoteuser -h server_ip_address -p
```
Example:

```bash
mysql -u ROOT -h 192.168.1.30 -p
```

Enter the password when prompted.

## 🛡️ Security Recommendations
- Avoid exposing MySQL direclty to the public internet unless absolutely necessary.
- Use strong passwords for MySQL users.
- Restrict allowed IPs **('root'@'IP')** instead of using **%** in production.
- Use VPN or SSH tunneling for encrypted connections.
- Monitor MySQL Logs for unauthorized access attempts.


✅ Verify Remote Access
Use this SQL command to view user permissions:

```bash
SELECT user, host FROM mysql.user;
```

✅ Done!
Your MySQL server is now ready to accept remote connections on Debian.
