# 🐧 How to Install (Web-Pentest Debain) in a Virtual Machine (Step-by-Step)

This guide walks you through installing **Debian Linux** inside a virtual machine using **VirtualBox** .

---

## 📋 Prerequisites

- ✅ Debian ISO: [https://www.debian.org/](https://www.debian.org/)
  - Recommended: **64-bit netinst ISO**
- ✅ Virtual machine software:
  - [VirtualBox](https://www.virtualbox.org/) (Free)
  - VMware Workstation or Player
- 💾 At least 30 GB of virtual disk space(60 GB recommended)
- 🧠 At least 2 GB of RAM (4 GB recommended for GUI)

---

## 🛠️ Step-by-Step Installation

### 🔹 Step 1: Download Debian ISO

1. Go to: [https://www.debian.org/](https://www.debian.org/)
2. Download the **64-bit netinst ISO** for the latest Debian release.
![App Screenshot](./img/Download%20Debain.png)
---

### 🔹 Step 2: Create a New Virtual Machine

####  In VirtualBox:

1. Click **New**.
2. Name: `Debian 12 or WebPentest-2025`
3. Type: `Linux`
3. Subtype: `Debain`
4. Version: `Debain 12 bookworm(64-bit)`
5. Memory: **2048 MB** or more.
6. Disk: Create a **20 GB** virtual hard disk (VDI or VHD format).

![App Screenshot](./img/create%20machine.png)

![App Screenshot](./img/Ram%20and%20CPU.png)

![App Screenshot](./img/Storage.png)

---

### 🔹 Step 3: Attach the ISO

1. Open **Settings** → **Storage**.
2. Under `Controller: IDE`, click `Empty`.
3. Click the disk icon and choose **the Debian ISO** file.

![App Screenshot](./img/image.png)

---

### 🔹 Step 4: Boot and Start Installer

1. Start the virtual machine.
2. Choose **Graphical Install** (recommended).

![App Screenshot](./img/Sel%20Graphical.png)
