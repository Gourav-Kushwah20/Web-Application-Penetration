# **PHP Script: HTML Page with Title and Heading**

This script creates a simple HTML5 page titled and headed with **"Armour Infosec"** using PHP.

---

## **Code**

```php
<!DOCTYPE html>
<html>
<head>
    <meta charset="utf-8">
    <title><?php echo "Armour Infosec"; ?></title>
</head>
<body>
    <h1><?php echo "Armour Infosec"; ?></h1>
</body>
</html>
```

---

## **Explanation**

* **`<!DOCTYPE html>`**: Declares the HTML5 document type.
* **`<meta charset="utf-8">`**: Ensures the page uses UTF-8 character encoding.
* **`<title>`**: Uses PHP to dynamically set the title as *"Armour Infosec"*.
* **`<h1>`**: Displays *"Armour Infosec"* as the main heading, also generated by PHP.

---

## **Tip**

You can define a variable for reuse:

```php
<?php
$title = "Armour Infosec";
?>
<!DOCTYPE html>
<html>
<head>
    <meta charset="utf-8">
    <title><?php echo $title; ?></title>
</head>
<body>
    <h1><?php echo $title; ?></h1>
</body>
</html>
```
