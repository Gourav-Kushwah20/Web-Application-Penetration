# Encode-and-Decode

## Encode and Decode in PHP (HTML Encoding Functions)

> When working with HTML output, encoding special characters is essential to prevent issues like broken HTML or security vulnerabilities (e.g., XSS). PHP provides several functions for encoding and decoding HTML entities.

---

## 1. htmlentities()

**Purpose:**  
Convert **all applicable characters** to their corresponding HTML entities. This means characters like `<`, `>`, `©`, quotes, accented characters, and others are encoded.

### Syntax:
```php
string htmlentities(
    string $string,
    int $flags = ENT_COMPAT | ENT_HTML401,
    ?string $encoding = null,
    bool $double_encode = true
)
```
---

$string: Input string to encode.

$flags: Controls how to handle quotes and document type (see below).

$encoding: Character encoding (default is UTF-8 if PHP >= 5.4).

$double_encode: Whether to encode existing entities again (default true).

## Common Flags:

| Flag         | Description                          |
|--------------|--------------------------------------|
| ENT_COMPAT   | Encode double quotes only            |
| ENT_QUOTES   | Encode both single and double quotes |
| ENT_NOQUOTES | Do not encode any quotes             |
| ENT_HTML401  | Handle code as HTML 4.01             |
| ENT_HTML5    | Handle code as HTML5                 |
| ENT_XML1     | Handle code as XML 1                 |
| ENT_XHTML    | Handle code as XHTML                 |

## Example:

```php
<?php
$str = "This is a <b>bold</b> & \"quoted\" text.";
echo htmlentities($str, ENT_QUOTES, 'UTF-8');
```

### Output:
```
This is a &lt;b&gt;bold&lt;/b&gt; &amp; &quot;quoted&quot; text.
```

---

## 2. html_entity_decode()

**Purpose:**  
Convert HTML entities back to their corresponding characters.

### Syntax:
```php
string html_entity_decode(
    string $string,
    int $flags = ENT_COMPAT | ENT_HTML401,
    ?string $encoding = null
)
```

> Decodes entities encoded by `htmlentities()`.

---

## 3. htmlspecialchars()

**Purpose:**  
Convert only **special characters** (`&, <, >, ", '`) to HTML entities.  
Useful when you want to prevent HTML injection but keep other characters intact.

### Syntax:
```php
string htmlspecialchars(
    string $string,
    int $flags = ENT_COMPAT | ENT_HTML401,
    ?string $encoding = null,
    bool $double_encode = true
)
```

> Parameters same as `htmlentities()`, but only targets a few special characters.

## Example:

```php
<?php
$str = "This is a <b>bold</b> & \"quoted\" text.";
echo htmlspecialchars($str, ENT_QUOTES, 'UTF-8');
```

### Output:
```
This is a &lt;b&gt;bold&lt;/b&gt; &amp; &quot;quoted&quot; text.
```

---

## 4. htmlspecialchars_decode()

**Purpose:**  
Reverse operation of `htmlspecialchars()`, converting encoded special characters back.

---

## 5. get_html_translation_table()

**Purpose:**  
Returns the array of characters and their corresponding HTML entities used by `htmlentities()` or `htmlspecialchars()`.

### Syntax:
```php
array get_html_translation_table(
    int $table = HTML_SPECIALCHARS,
    int $flags = ENT_COMPAT | ENT_HTML401
)
```

### $table:

- `HTML_ENTITIES` — Returns all entities like `&nbsp;`, `&copy;`, etc.
- `HTML_SPECIALCHARS` — Returns only special characters (`<`, `>`, `"`, `&`).

# htmlentities.php Example

```php
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="utf-8">
    <title>htmlentities Example</title>
</head>
<body>
    <?php
        $str = "We are <a href='https://www.armourinfosec.com/'>Armour Infosec</a>. A knowledge-based and technical security solutions provider, offering <b>Ethical Hacking & Cyber Security</b> courses.";

        // Original string output (with HTML tags rendered)
        echo "Original string:<br>" . $str . "<br><br>";

        // Convert all applicable characters to HTML entities
        $encoded = htmlentities($str, ENT_QUOTES, 'UTF-8');
        echo "After htmlentities (all applicable chars encoded):<br>" . $encoded . "<br><br>";

        // Decode entities back to original string
        echo "After html_entity_decode:<br>" . html_entity_decode($encoded, ENT_QUOTES, 'UTF-8');
    ?>
</body>
</html>
```
# htmlspecialchars.php Example

```php
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="utf-8">
    <title>htmlspecialchars Example</title>
</head>
<body>
    <?php
        $str = "We are <a href='https://www.armourinfosec.com/'>Armour Infosec</a>. A knowledge-based and technical security solutions provider, offering <b>Ethical Hacking & Cyber Security</b> courses.";

        echo "Original string:<br>" . $str . "<br><br>";

        // htmlentities encodes all applicable characters
        $entities = htmlentities($str, ENT_QUOTES, 'UTF-8');
        echo "htmlentities:<br>" . $entities . "<br><br>";

        // htmlspecialchars encodes only special characters
        $specials = htmlspecialchars($str, ENT_QUOTES, 'UTF-8');
        echo "htmlspecialchars:<br>" . $specials . "<br><br>";

        // Decoding htmlspecialchars entities
        echo "After htmlspecialchars_decode:<br>" . htmlspecialchars_decode($specials, ENT_QUOTES, 'UTF-8');
    ?>
</body>
</html>
```

# PHP Functions for HTML Encoding

## 1. `htmlspecialchars()`

**What it encodes:**  
Only the most important characters that have special meaning in HTML:

- `&` (ampersand) → `&amp;`  
- `<` (less than) → `&lt;`  
- `>` (greater than) → `&gt;`  
- `"` (double quote) → `&quot;` (if `ENT_QUOTES` flag is set)  
- `'` (single quote) → `&#039;` (if `ENT_QUOTES` flag is set)

**Use case:**  
When you want to preserve readable text but prevent it from being interpreted as HTML code.  
Ideal for outputting user input inside HTML (e.g., in form fields, comments, etc.).

**Example:**
```php
$str = 'This is a <b>bold</b> & "quoted" text with 'single quotes'.';
echo htmlspecialchars($str, ENT_QUOTES, "UTF-8");
```

**Output:**
```
This is a &lt;b&gt;bold&lt;/b&gt; &amp; &quot;quoted&quot; text with &#039;single quotes&#039;.
```

---

## 2. `htmlentities()`

**What it encodes:**  
All characters that have HTML entity equivalents, including special characters AND characters with accents, currency symbols, etc.

**Use case:**  
When you want to convert all applicable characters to their HTML entity equivalents.  
Useful if you want to display HTML code literally, including accented or special symbols, or when working with legacy content where full encoding is needed.
