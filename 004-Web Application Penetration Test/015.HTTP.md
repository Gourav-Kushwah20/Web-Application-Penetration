# 🌐 HTTP (Hypertext Transfer Protocol)

HTTP is an application-layer protocol used for transmitting hypermedia documents, like HTML.  
It forms the foundation of data communication on the **World Wide Web**.

---

## 🔑 Key Characteristics

- **Client-Server Model**: Client sends a request; server returns a response.  
- **Stateless Protocol**: Server doesn't retain information between requests.  
- **Text-based Communication**: Human-readable format for headers and payload.  

---

## 📋 HTTP Headers

HTTP headers are key-value pairs sent in both requests and responses to carry metadata.  

**Examples:**

    Content-Type: application/json
    Authorization: Bearer <token>
    User-Agent: Mozilla/5.0

---

## 📡 HTTP Request Methods

| **Method** | **Description** |
|------------|-----------------|
| `GET`      | Retrieve data from the server |
| `POST`     | Submit data to the server (e.g., form submission) |
| `PUT`      | Update/replace a resource |
| `PATCH`    | Partially update a resource |
| `DELETE`   | Remove a resource |
| `HEAD`     | Like GET, but returns headers only (no body) |
| `OPTIONS`  | Describe the communication options for a resource |
| `TRACE`    | Echoes the received request (used for debugging) |
| `CONNECT`  | Establish a tunnel to the server (e.g., for HTTPS) |

---

## 📊 HTTP Response Status Codes

| **Category**     | **Range**  | **Meaning** |
|------------------|------------|-------------|
| 🔵 Informational | `100–199`  | Request received, continue process |
| 🟢 Success       | `200–299`  | Request successfully received, understood, and accepted |
| 🟠 Redirection   | `300–399`  | Further action must be taken to complete the request |
| 🟡 Client Error  | `400–499`  | Request contains bad syntax or cannot be fulfilled |
| 🔴 Server Error  | `500–599`  | Server failed to fulfill a valid request |
