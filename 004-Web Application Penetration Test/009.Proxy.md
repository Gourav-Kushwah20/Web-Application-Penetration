<h1 style="color:#32CD32;">🌐 What is a Proxy?</h1>

A **proxy server** is an intermediary between your device and the internet. It forwards your requests to the destination server and then sends the response back to you.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━  
🎯 **Flow**:  
🧑 You → 🛡️ Proxy → 🌍 Website  
🌍 Website → 🛡️ Proxy → 🧑 You  
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

<h2 style="color:#32CD32;">🧠 What Does a Proxy Do?</h2>

| 🛠️ **Function**        | 💬 **Description** |
|------------------------|-------------------|
| 🔒 **Anonymity**        | Hides your real IP address. |
| 🚫 **Content Filtering**| Blocks/filters specific websites. |
| 📊 **Access Control**   | Controls who can access what. |
| ⚡ **Caching**          | Speeds up browsing by storing data. |
| 🌍 **Bypass Geo-blocks**| Access region-locked content. |
| 🧪 **Traffic Inspection**| Intercepts and analyzes requests (e.g., with Burp Suite). |

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

<h2 style="color:#32CD32;">🧰 Types of Proxies</h2>

| 🧩 **Type**         | 📘 **Description** |
|--------------------|-------------------|
| 🔀 Forward Proxy    | Client-side, hides user's identity. |
| 🔁 Reverse Proxy    | Server-side, balances traffic. |
| 👻 Transparent Proxy| Works without user knowing. |
| 🧦 SOCKS Proxy      | Works with any protocol (not just web). |
| 🌐 HTTP Proxy       | Handles only web (HTTP/HTTPS) traffic. |

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

<h2 style="color:#32CD32;">💡 Real-World Uses</h2>

- 🧪 **Pentesting tools** like Burp Suite or OWASP ZAP  
- 🌍 **Bypass blocked sites** (e.g., Netflix region locks)  
- 👨‍💼 **Corporate control** over internet access  
- 🔍 **Monitoring** employee or student activity  
- 🤖 **Web scraping** for data collection
