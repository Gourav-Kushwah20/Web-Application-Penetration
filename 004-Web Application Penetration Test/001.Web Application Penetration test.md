# 🌐 Web Application – Definition and Examples

## What is a Web Application?

A **Web Application** is a software program that runs on a **web server** and can be accessed via a **web browser** using the Internet or an intranet. Unlike desktop applications, web apps do not require installation on a user's machine.

---

## ⚙️ Components of a Web Application

| Component     | Description |
|---------------|-------------|
| **Frontend**  | The user interface, built using HTML, CSS, JavaScript |
| **Backend**   | The server-side logic, built using languages like PHP, Python, Node.js |
| **Database**  | Stores application data (e.g., MySQL, PostgreSQL, MongoDB) |
| **Web Server**| Hosts and serves the application (e.g., Apache, Nginx) |

---

# 🛡️ Web Application Penetration Testing

## What is Web Application Penetration Testing?

**Web Application Penetration Testing** is the process of testing a website or web application to find weaknesses (called vulnerabilities) that attackers could use to break in or steal data.

EX :- It’s like checking all the doors and windows of a house to make sure everything is locked and secure.

---

## ✅ Why Is It Done?

- To protect **user data** (e.g., passwords, credit card info)
- To stop hackers from gaining access or control
- To fix problems before real attackers find them
- To follow legal and security rules (like GDPR [General Data Protection Regulation], PCI-DSS [Payment Card Industry - Data Security Standard.])

---

## 🔍 What Does a Tester Check?

- **Login systems** – Are usernames and passwords safe?
- **Input fields** – Can someone enter harmful code?
- **User permissions** – Can regular users access admin features?
- **File uploads** – Can attackers upload dangerous files?
- **APIs** – Are backend services properly protected?

# 🔐 What is SSDLC?

**SSDLC** stands for **Secure Software Development Life Cycle**.  
It is a process that integrates **security practices** into every phase of the software development life cycle to build secure and reliable applications.

---

## 🛠️ Why is SSDLC Important?

- Prevents security issues early in the development process  
- Reduces time and cost to fix vulnerabilities  
- Helps protect sensitive data from cyberattacks  
- Ensures compliance with laws and standards (e.g., GDPR, PCI-DSS)  
- Improves overall software quality and trust

---

## 📋 Key Phases of SSDLC

1. **Requirement Analysis**  
   - Define both functional and **security requirements**.

2. **Design**  
   - Use **secure design principles** (e.g., least privilege, defense in depth).

3. **Development**  
   - Follow **secure coding practices** to avoid common bugs.

4. **Testing**  
   - Perform **security testing** (e.g., static analysis, penetration testing).

5. **Deployment**  
   - Ensure **secure configuration** and restrict access.

6. **Maintenance and Monitoring**  
   - Monitor for new threats and apply updates or patches regularly.

---

## ✅ Summary

SSDLC helps create software that is **secure by design**, **resilient to attacks**, and **trusted by users**. It’s a best practice for modern software development.
