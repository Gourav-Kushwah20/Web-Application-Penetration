# Burp Suite

**Burp Suite** is a powerful integrated platform used primarily for **web application penetration testing**. It's developed by **PortSwigger** and offers a range of tools to help security professionals identify and exploit vulnerabilities in web applications.

---

## What Is Burp Suite?

Burp Suite acts as an **intercepting proxy** that sits between your browser and the target web application. It allows you to:

- Inspect and modify **HTTP/S traffic** on the fly.
- Automate scans for **common web vulnerabilities**.
- **Manually test** for complex security issues.
- Reproduce and refine attacks like **SQL Injection (SQLi)**, **Cross-Site Scripting (XSS)**, and **Cross-Site Request Forgery (CSRF)**.

---

## Core Tools in Burp Suite

| Tool     | Functionality                                                                 |
|----------|--------------------------------------------------------------------------------|
| **Proxy**     | Intercepts traffic between your browser and the server.                      |
| **Intruder**  | Automates customized attacks (e.g., fuzzing, brute-force attacks).           |
| **Repeater**  | Allows manual modification and resending of HTTP requests.                   |
| **Scanner**   | Automatically scans for security issues (available in **Pro version**).      |
| **Decoder**   | Encodes, decodes, and transforms data (e.g., Base64, URL, Hex).              |
| **Comparer**  | Compares differences between HTTP requests or responses.                     |
| **Extender**  | Adds plugins or extensions via the **BApp Store** or custom-written code.    |

---
## Burp Suite: Typical Workflow and Use Cases

## Typical Workflow

1. **Set browser proxy** to `127.0.0.1:8080`.
2. **Start Burp Suite** and enable the proxy.
3. **Intercept requests** from the browser (e.g., visiting `http://example.com`).
4. Use **Repeater** to modify and replay interesting requests.
5. Use **Intruder** to automate payload testing (e.g., fuzzing or brute-force attacks).
6. **Review results** and analyze responses to identify security vulnerabilities.

---

## HTTPS Interception

To intercept **HTTPS traffic**:

- **Install Burp's CA certificate** into your browser or system.
  - This is required to avoid security warnings when intercepting HTTPS.
  - The certificate can be downloaded from `http://burp` when Burp is running.
- This allows Burp Suite to **decrypt and inspect HTTPS traffic** securely.

# Burp Suite Directory and Chrome HTTPS Setup

## BurpSuite

Burp Suite is commonly used in penetration testing and requires some browser and system configuration for effective HTTPS interception.

---

## Chrome Browser Setup for Burp Suite

To prepare Chrome for working with Burp Suite:

1. Navigate to: `chrome://settings/security`
2. Scroll to **"Advanced"**.
3. Find **"Always use secure connections"** and **turn it OFF**.

> This setting forces HTTPS-only connections. Disabling it allows Burp to properly intercept HTTP and HTTPS traffic.

---

## How HTTPS Works

HTTPS (Hypertext Transfer Protocol Secure) relies on **TLS (Transport Layer Security)**, which uses **asymmetric encryption** to secure data between the client and server.

### Key Types in HTTPS:

| Key Type     | Description                                                                 |
|--------------|-----------------------------------------------------------------------------|
| **Private Key** | Stored securely on the **web server**. Used to **decrypt** data sent by clients. |
| **Public Key**  | Shared openly with clients. Used to **encrypt** data before sending to the server. |

This mechanism ensures that even if someone intercepts the traffic, they cannot read it without the private key.

# Installing Burp CA Certificate on Kali Linux

## Step 1: Intercept in Burp
- Open your browser with Burp proxy enabled.
- Visit: `http://burp`
- Click on **"CA Certificate"** to download the certificate (`cacert.der`).

## Step 2: Use `curl` With Proxy
```bash
curl https://www.google.com --proxy 127.0.0.1:8080
```

## Step 3: Convert DER to CRT
Convert the downloaded DER certificate to CRT format using OpenSSL:
```bash
openssl x509 -in cacert.der -inform DER -out cacert.crt
```

## Step 4: Add to System Certificate Store
Copy the certificate to the system's trusted store and update certificates:
```bash
cp cacert.crt /usr/local/share/ca-certificates/
```
```bash
update-ca-certificates
```

## Step 5: Verify With `curl`
Use `curl` to make sure the certificate is recognized:
```bash
curl https://www.google.com --proxy 127.0.0.1:8080 --cacert cacert.crt
```

## Step 6: Using With Tools (e.g., dirsearch)
Use tools like `dirsearch` with Burp proxy enabled:
```bash
dirsearch -u https://www.google.com --proxy 127.0.0.1:8080
```

## 🌿 **Burp Suite CA Certificate Cleanup & Runtime Configuration** 🌿
## 🧹 **Step 7: Remove Certificate (Cleanup)**

```bash
rm -fv /usr/local/share/ca-certificates/cacert.crt
```
```bash
update-ca-certificates --fresh
```

## Installing Burp Suite CA Certificate on Kali Linux

To intercept HTTPS traffic, Burp's custom Certificate Authority (CA) certificate must be installed on the system or browser.

### Step-by-Step:

1. **Enable Intercept** in Burp Suite (under the **Proxy** tab).
2. Open your **browser with the proxy enabled**.
3. Navigate to: `http://burp` (Burp's local web interface).
4. Click on the **CA Certificate** download link.
5. Save the file (typically named `cacert.der` or `cacert.cer`).

You can now import this certificate into your browser or system certificate store to trust Burp for HTTPS interception.

---
## Installing Burp Suite CA Certificate on Windows

This guide explains how to install the Burp Suite CA (Certificate Authority) certificate on Windows to enable HTTPS traffic interception without browser warnings.

---

## 📥 Step 1: Export the Burp CA Certificate

1. Open **Burp Suite**.
2. Navigate to **Proxy > Options**.
3. Ensure a proxy listener is running (usually on `127.0.0.1:8080`).
4. In your browser, go to:  

- visit URL: http://burpsuite
- OR : http://127.0.0.1:8080

5. Click the **"CA Certificate"** link to download it.  
The file will be saved as `cacert.der`.

---

## 📁 Step 2: Convert (Optional)

Rename the downloaded file:

- From: `cacert.der`  
- To: `cacert.cer`

> This step helps Windows recognize the certificate format.

---

## ⚙️ Step 3: Install the Certificate into Windows Trust Store

1. Double-click the `cacert.cer` file.
2. Click **Install Certificate**.
3. Choose **Local Machine** (admin rights required), then click **Next**.
4. Select **Place all certificates in the following store**, then click **Browse**.
5. Choose **Trusted Root Certification Authorities**.
6. Click **OK**, then **Next**, then **Finish**.
7. Confirm the security warning by clicking **Yes**.

---

## ✅ Step 4: Verify the Installation

1. Press `Windows + R`, type `certmgr.msc`, and press Enter.
2. In the left pane, expand **Trusted Root Certification Authorities > Certificates**.
3. Look for **PortSwigger CA** or similar.

---

## 🌐 (Optional) Configure Your Browser Proxy

To route traffic through Burp:

- Set the system/browser proxy to:
    
    Address: 127.0.0.1
    
    Port: 8080

> For Chrome and Edge, configure this through **Internet Options > Connections > LAN Settings**.

---

## 🔄 Firefox Users

Firefox does **not** use the Windows certificate store by default.

To install the certificate in Firefox:

1. Open **Firefox > Settings > Privacy & Security**.
2. Scroll to **Certificates**, click **View Certificates**.
3. Go to the **Authorities** tab.
4. Click **Import**, select the `cacert.cer` file.
5. Enable **"Trust this CA to identify websites"**.
6. Click **OK**.
